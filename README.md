# Advanced Machine Learning

Practical notebooks, study notes, exercises, and datasets for advanced machine-learning topics.

## Repository structure

| Folder | Contents |
| --- | --- |
| `DBSCAN Clustering` | DBSCAN clustering notebooks and practice work |
| `Decision Tree` | Decision-tree notebooks, notes, and exercises |
| `Final Exam` | Final assessment notebook and the `bank.csv` dataset |
| `K-Means Clustering` | K-means, K-nearest-neighbors, and grid-search notebooks |
| `Principal Component Analysis (PCA)` | PCA notebooks, notes, and practice work |
| `Random Forest` | Random-forest notebooks, notes, and exercises |
| `Support Vector Machine` | SVM notebook, notes, and practice work |

Each topic folder keeps its related Jupyter notebooks, PDF reference material,
practice problems, and datasets together.

## Getting started

1. Install Python 3 and Jupyter:

   ```bash
   python -m pip install jupyter numpy pandas scikit-learn matplotlib seaborn
   ```

2. Clone this repository and open it in Jupyter Notebook or JupyterLab:

   ```bash
   git clone https://github.com/Rayhan043/Advance-Machine-Learning.git
   cd Advance-Machine-Learning
   jupyter lab
   ```

3. Open a notebook from the relevant topic folder and run the cells in order.

The notebooks use the `python3` Jupyter kernel. Some exercises may require
additional packages or datasets referenced in the notebook itself.

- PDF files are included as reference notes and practice material.
